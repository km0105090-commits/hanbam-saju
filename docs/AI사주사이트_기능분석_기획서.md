## 1부. 벤치마크 사이트 기능 분석

### 1-1. 확인 방법과 한계
- 2026-11-18 브라우저로 홈, 상품 소개(연애·총운), 입력 폼, 오늘의 운세, 내 정보, 이용약관을 직접 열어 봤다.
- 입력 폼은 마지막 단계(이메일)까지 테스트 값으로 진행하고 **제출하지 않았다.** 그래서 **결과 화면·잠금 미리보기·결제 화면·가격은 직접 확인하지 못했다.** 아래 해당 항목은 외부 후기와 화면 구성으로 추정한 것이며 "추정"이라고 표시했다.
- 확인이 더 필요하면 민님이 직접 상품 1개를 결제해 보는 게 가장 정확하다 (가격·잠금 위치·결과 구성·업셀 화면).

### 1-2. 정보 구조 (화면 맵)
| 화면 | URL 형태 | 확인된 기능 |
|---|---|---|
| 홈 | `/` | 카테고리 탭(전체·무료·총운·연애·재회·결혼·가정·기타), 상품 카드 캐러셀, "매출 1~5위·BEST" 뱃지, 상단에 상품명 키워드 롤링 |
| 상품 소개 | `/bot/{id}/intro` | 캐릭터 일러스트 히어로 + 배경음(음소거 버튼), 목차 미리보기, 결과 예시 문장 3개(후킹), 차별점 3개, 리뷰(평점·리뷰 수·일주 표시·페이지네이션), 하단 고정 CTA 버튼 |
| 입력 폼 | `/bot/{id}/form` | **캐릭터가 말 거는 채팅형 1문항 1화면** 폼 (아래 1-3) |
| 오늘의 운세 | `/today` | 오늘 날짜·일진(간지)·한 줄 요약은 비로그인 공개 → 개인 운세 2줄은 흐리게 → "카카오로 계속하기" |
| 보관함 | `/box` | 구매한 리포트 모아 보기 (로그인 필요) |
| 내 정보 | `/mypage` | 카카오 로그인, 카카오 채널 추가 시 할인 쿠폰, 내 만세력, 리포트, **채팅방**, 쿠폰, **선물하기**, **초대하기**, **무료이용권 받기**, 고객센터 |
| 약관·방침·문의 | `/terms` `/privacy` `/cs` | 하단 사업자 정보 6항목 표기 |

- 모바일 웹 전용 레이아웃(가운데 좁은 단, 하단 탭바: 홈·오늘의 운세·보관함·내 정보).
- 상품 수가 많다 (홈 롤링에만 30개 이상). 같은 주제를 여러 "캐릭터 상품"으로 쪼갠다 (재회만 사주·타로·점성술·자미두수 등 8종 이상).

### 1-3. 입력 폼 흐름 (연애 상품 기준, 확인됨)
1. 이름 → 2. 성별 → 3. 양력/음력 선택 후 생년월일(`YYYY.MM.DD`) → 4. 태어난 시간 (**"시간모름" 버튼**) → 5. 현재 연애 상태(5지선다) → 6. 가장 알고 싶은 것(4지선다) → 7. 직업(4지선다) → 8. 이메일 → "풀이 보기" 버튼
- 각 단계마다 캐릭터가 앞 답을 받아 한마디 하고 다음 질문을 던진다 (이름 부르기 → 맞춤감).
- 상품별로 5~7번 질문이 바뀐다 (= 프롬프트에 넣을 상품 전용 변수).
- **로그인보다 입력이 먼저**다. 이메일만 받고 결과 화면으로 넘긴 뒤 로그인·결제를 받는 구조로 보인다 (추정).

### 1-4. 수익 구조 (확인 + 추정)
- **무료 미끼**: 오늘의 운세(일진), "무료" 카테고리, 무료이용권, 결과 일부 공개 (추정).
- **유료 단건 리포트**: 외부 후기 기준 2만 원대 초반 상품이 있고, 쿠폰 적용 시 1만 원대 중반 (추정, 직접 확인 안 함).
- **할인 장치**: 카카오 채널 추가 쿠폰(2,000원), 첫 결제 쿠폰, 추천 코드(초대하기), 선물하기.
- **재구매 장치**: 채팅방(리포트 뒤 캐릭터와 추가 대화로 보임), 보관함, 내 만세력 저장, 상품 다수·카테고리 교차 추천.
- **신뢰 장치**: 리포트 하나에 리뷰 수백 개, 리뷰는 유료 결제자만 작성 가능(약관), 실시간 "방금 1명이 확인했어요" 알림.
- 약관상 In-App 결제·7일 청약철회 조항이 있다 (앱 버전도 운영하는 것으로 보임).

### 1-5. 우리가 가져갈 것 / 버릴 것
| 가져갈 구조 | 버릴 것 (리스크) |
|---|---|
| 채팅형 1문항 입력 폼, "시간모름" 처리 | "정확도 200%", "신점보다 용하다" 같은 근거 없는 표현 |
| 입력 → 무료 일부 공개 → 잠금 → 결제 퍼널 | "몇 월 며칠에 연애 시작", "놓치면 3년 혼자" 같은 단정·공포형 카피 |
| 캐릭터별 상품 (말투가 상품 차별점) | 그 사이트의 캐릭터 이름·외모·세계관, 상품명, 카피 문장 |
| 오늘의 운세로 매일 방문 + 로그인 유도 | "매출 1위" 뱃지를 근거 없이 쓰는 것 |
| 보관함·내 만세력·쿠폰·추천 코드·선물하기 | 리뷰 조작으로 보일 수 있는 운영 (리뷰는 실제 구매자만) |
| 상품 상세의 목차 미리보기 + 결과 예시 | 상품 30개 동시 운영 (초기엔 감당 불가) |

## 2부. 우리 사이트 기획

### 2-1. 브랜드 제안 (가칭)
| 후보 | 콘셉트 | 메모 |
|---|---|---|
| **별숨** (1순위) | "별이 숨 쉬는 시간", 차분한 밤하늘 톤 | 짧고 기억 쉬움, 도메인 `byeolsum` 계열 |
| 결 (結) 사주 | 사람·인연의 결, 연애·궁합 중심 | 한 글자라 상표 등록이 어려울 수 있음 |
| 새벽편지 | 밤에 사주 보는 사람에게 편지 쓰듯 (전자책의 "편지 톤") | 서술형이라 식별력 보강 필요 |

- 확정 전 **KIPRIS(특허정보검색)에서 45류(점술)·41류·9류 동일·유사 상표**, 도메인, 인스타 계정명이 비어 있는지 확인. 확정 후 상표 출원 권장 (1류당 출원료 약 5만 원대, 변리사 대행 시 추가).
- 톤: 공포·단정 없이 "흐름을 읽어 주는 다정한 안내자". 전자책 원칙(참고용·보장 안 함)을 브랜드 약속으로 앞세운다.

### 2-2. 캐릭터 (자체 창작, 3명으로 시작)
전자책의 캐릭터 4유형을 바탕으로 **이름·외모·말투를 전부 새로 만든다.** 이미지 생성 시 실존 인물·작가명·타사 캐릭터 레퍼런스 금지.
| 캐릭터 (가칭) | 유형 | 말투 | 담당 상품 |
|---|---|---|---|
| 달이 | 젊은 여성 안내자 | 친근한 반말, 직설이지만 위로 포함 | 연애운, 재회운, 궁합 |
| 소운 선생 | 중년 남성 학자 | 차분한 존댓말, 근거 설명형 | 평생사주, 재물·직업운, 신년운 |
| 온할매 | 푸근한 할머니 | 다정한 사투리 섞인 존댓말 | 가족·아이 사주, 무료 오늘의 운세 |

- 캐릭터는 "말투 프롬프트 + 일러스트 3컷(기본·웃음·고민)"으로 정의한다. 결과 화면 섹션마다 말풍선으로 등장.

### 2-3. 상품 라인업과 가격 (초기 6개)
전자책은 "첫 상품은 하나만", 안내서는 저가 다품목을 권한다. 사이트는 결제 자동화라 운영 부담이 작으므로 **무료 1 + 유료 5**로 시작하고, 1~2개월 데이터를 보고 늘린다.
| 단계 | 상품 | 가격 (안) | 입력 | 결과 | AI 원가(안내서) |
|---|---|---|---|---|---|
| 무료 | 오늘의 운세 | 0원 (로그인 시 개인화) | 생년월일 저장값 | 화면 | 거의 0 (캐시) |
| 무료 미끼 | 내 사주 맛보기 | 0원 | 기본 7항목 | 1~3번 섹션 공개, 나머지 잠금 | 약 100원 |
| 입문 | 연애운 / 신년운 | 4,900원 | 기본 + 상품 질문 3개 | 웹 리포트 11섹션 | 약 150~250원 |
| 주력 | 재회운 / 궁합 | 12,900원 | 본인 + 상대 정보 | 웹 + PDF | 약 350~600원 |
| 프리미엄 | 평생사주 | 19,900원 | 기본 7항목 | 웹 + PDF (가장 긺) | 약 500원 |
| 추가 | 캐릭터와 추가 질문 3회 | 2,900원 | 질문 텍스트 | 채팅 | 약 50원/회 |

- 가격 근거: 안내서의 990~24,900원 표와 전자책의 "1만 원 이하는 대충 뽑나 의심" 사이. 벤치마크도 2만 원대 + 쿠폰 구조로 보여 중간값에 둔다.
- 시즌 상품(12~2월 신년운, 2·12월 연애·재회)은 전자책 시즌 캘린더를 따라 홈 배너만 교체.

### 2-4. 핵심 사용자 흐름
```
광고·릴스·검색 → 홈 또는 상품 소개
 → 채팅형 입력 (로그인 없이)
 → [서버] 만세력 계산 → 무료 섹션 1~3 생성 → 결과 화면 (나머지 섹션 목차만 보이고 잠금)
 → "전체 보기" → 카카오 로그인 → 동의 체크 → 토스 결제
 → [서버] 결제 확인 웹훅 → 잔여 섹션 생성 (섹션별 순차) → 결과 화면 실시간 채움
 → Resend로 완료 메일 (웹 링크 + PDF) → 보관함 저장
 → 다음 날 후기 요청 메일 → 리뷰 작성 시 쿠폰 → 다음 상품 추천
```
- **계산은 만세력, 해석만 AI** (전자책 핵심 원칙). 사주 여덟 글자는 코드 라이브러리로 확정해서 프롬프트에 넣는다. 절기 경계·자시·윤달 테스트 케이스 필수.
- 무료 섹션을 먼저 만들어 보여 주고, 결제 후 나머지를 만든다 → 결제 안 한 사람에게 쓰는 AI 비용 최소화.

### 2-6. 결과 화면 구성 (전자책 11목차 → 웹)
| # | 섹션 | 무료/유료 | 시각 요소 |

## 3부. 법적 리스크와 대응

### 3-1. 저작권
- **문구·카피**: 벤치마크의 상품명·소개 문장·리뷰 문구를 그대로 또는 살짝 바꿔 쓰지 않는다. 카피는 전부 새로 쓴다.
- **캐릭터·일러스트**: 이름·외모·의상·그림체가 비슷하면 저작권 침해나 부정경쟁 소지. 이미지 생성 시 타사 캐릭터를 레퍼런스로 넣지 않는다.
- **UI 디자인**: 레이아웃 아이디어(채팅형 폼 등)는 보호 대상이 아니지만, 색·배치·그래픽을 통째로 따라 하면 "트레이드 드레스"(부정경쟁방지법 차목·카목 성과물 도용) 문제가 될 수 있다.
- **만세력 라이브러리**: 오픈소스 라이선스(MIT/GPL 등) 확인. GPL이면 상용 서비스 배포 조건 검토.
- **AI 생성물**: Claude 출력은 서비스 약관상 우리가 쓸 수 있으나, 리포트 안에 타인의 책·사이트 문장이 섞이지 않도록 프롬프트에 원문 인용 금지.

### 3-2. 상표
- "용용", "용용사주", 해당 사이트 캐릭터명은 **광고 키워드·메타태그·해시태그에도 쓰지 않는다.** 경쟁사 상표를 검색광고 키워드로 사는 것도 분쟁 사례가 있다.
- 우리 브랜드는 KIPRIS로 선행 상표 확인 후 출원. 등록 전에는 ™ 표기만, ® 표기는 등록 후.

### 3-3. 과장·허위 광고 (표시광고법, 전자상거래법)
- 금지 예: "정확도 200%", "신점보다 용하다", "100% 맞힘", "반드시 재회", 특정 날짜 단정, "놓치면 3년 혼자" 같은 공포 유발.
- "매출 1위·BEST·리뷰 수"는 **실제 데이터로만**, 기준(기간·대상)을 함께 표기.
- 리뷰: 대가성 후기(쿠폰 지급 후기)는 "후기 작성 시 쿠폰 제공" 사실을 표시. 가짜 리뷰·리뷰 선별 노출은 공정위 제재 사례가 있다.
- "실시간 ○명이 확인 중" 같은 알림은 실제 수치가 아니면 넣지 않는다 (다크패턴 규제 대상).
- 할인: "정가"는 실제 판매한 적 있는 가격이어야 한다. 상시 할인을 정가 대비 할인처럼 표시하면 위반 소지.

### 3-4. 결제·환불 (전자상거래법)
- 디지털 콘텐츠는 **결제 전에 "제공이 시작되면 청약철회가 제한된다"는 사실을 고지하고 동의**를 받아야 철회 제한이 인정된다. 고지 없이 "환불 불가"만 쓰면 효력 문제.
- 결제 후 생성 실패·지연 시 자동 환불 또는 재생성. 전자책 환불 4줄 규정을 사이트용으로 옮긴다.
- 다크패턴 금지 (2025년 시행 개정 전자상거래법): 숨은 추가 비용, 해지 방해, 순차적 가격 공개 등에 주의. 잠금 미리보기의 가격은 **잠금 버튼 위에 처음부터 표시.**

### 3-5. 개인정보 (개인정보보호법)
- 생년월일시·이름·이메일은 개인정보. 수집 항목·목적·보관 기간을 처리방침과 입력 화면에 고지.
- **상대방(궁합·재회) 정보는 제3자 정보** → 최소 수집(이름 대신 호칭 허용), "상대방 동의 범위에서 입력" 안내, 짧은 보관 기간.
- Claude API·Supabase·Vercel·Resend는 국외 이전·처리위탁 → 처리방침에 수탁자·이전 국가 명시.
- 만 14세 미만은 법정대리인 동의 필요 → 가입 제한이 가장 간단.

### 3-6. 콘텐츠 안전
- 전자책 금지 블록(건강·투자·법률 결정 유도, 죽음·사고·질병 암시, "반드시/100%/무조건")을 시스템 프롬프트와 출력 후 금지어 필터 **두 군데**에 둔다.
- 면책 문구는 상품 소개·결제 전·결과 하단 세 곳.
- 우울·자해 신호가 입력되면 상품 대신 상담기관 안내.
