# 한밤사주 AI 풀이 프롬프트 (상품별)

민님이 주신 6덩어리 틀(역할, 원칙, 목차, 분량, 금지, 면책)을 그대로 쓰고, 상품마다 **목차 11개**와 **캐릭터 한 줄**, **손님 정보 덩어리**만 바꿨어요.

- **금지**와 **면책**은 네 상품 모두 민님 원문 그대로예요.
- **목차**는 민님의 11개 뼈대를 네 상품 모두 그대로 쓰고, **6번 주제만** 상품에 맞게 바꿨어요 (연애: 연애운 흐름 / 궁합: 두 사람의 관계 구조 / 인생: 평생 운의 큰 흐름 / 신년: 2027년 열두 달 흐름). 신년운세의 '올해와 향후 흐름'은 2027년 세운과 지금 대운을 중심으로, '시기별 조언'은 달 단위로 쓰게 돼요.
- **손님 정보**는 사이트에서 받은 값으로 채워요. 상담 장면에서 고른 답(예: "요즘 좀 외로워서요")은 `참고 대화`로 따로 붙여서, 10번 항목과 전체 말투에 반영되게 했어요.
- 사용법은 두 가지예요. **A. 채팅용**은 민님 틀 그대로 "다음"을 눌러 가며 한 항목씩 받아요. **B. 자동 생성용**은 사이트에서 결제가 끝나면 11번 반복 호출해서 PDF를 만들어요. 맨 아래에 따로 정리했어요.

---

## 공통 덩어리 (네 상품 모두 그대로)

**[원칙]**
해석은 희망적이고 건설적인 방향으로 씁니다. 약점은 반드시 보완법과 함께 적습니다. 단정적인 예언은 하지 않고 '이 시기에는 상대적으로 ~한 기운이 강합니다'처럼 흐름으로 표현합니다.

**[분량]**
각 항목은 소제목을 달고 4~6문단으로 씁니다. 항목마다 예시 상황 2개와 표 1개, 마지막에 체크리스트 3줄을 넣습니다. 한 번에 한 항목씩만 작성하고, 제가 '다음'이라고 하면 다음 항목으로 넘어갑니다.

**[금지]**
건강·투자·법률에 관한 결정을 유도하지 않습니다. 구체적인 금액·종목·병명·소송 결과를 언급하지 않습니다. 죽음·사고·질병을 암시하는 표현과 공포를 조장하는 문장을 쓰지 않습니다. '반드시', '100%', '무조건' 같은 단어를 쓰지 않습니다.

**[면책]**
마지막 항목 끝에 다음 문장을 그대로 넣습니다. '이 리포트는 사주명리학을 바탕으로 AI가 구성한 참고용 콘텐츠입니다. 미래를 예측하거나 결과를 보장하지 않으며, 건강·재정·법률 등 중요한 결정은 반드시 해당 분야 전문가와 상의해 주세요.'

> 참고: 금지 블록은 '반드시'를 쓰지 말라고 하는데, 원칙과 면책 문장에는 '반드시'가 들어 있어요. 원칙의 '반드시'는 AI에게 하는 지시라 괜찮고, 면책 문장은 그대로 넣으라는 문장이라 예외예요. AI가 헷갈려서 면책 문장을 고치는 경우가 있으면 금지 블록 끝에 "(단, 면책 문장은 예외로 원문 그대로 둡니다)"를 붙이세요.

## 손님 정보 덩어리 (사이트 값으로 채우기)

민님 형식을 그대로 두고, 뒤에 **여덟 글자**와 **참고 대화** 두 줄을 붙였어요. 여덟 글자를 AI가 직접 계산하면 가끔 틀려서, 만세력으로 계산한 값을 박아 넣는 게 안전해요.

```
고객 정보: 이름 {이름}, {년}년 {월}월 {일}일 {양력|음력}{, 윤달}, {태어난 시간 | 시간 모름 → 시주 제외}생, {성별}, 궁금한 점: {고른 질문}.
만세력 기준 사주 구성: 년주 {년주}, 월주 {월주}, 일주 {일주}, 시주 {시주 | 모름}. 이 여덟 글자를 확정된 것으로 보고 해석해 주세요.
참고 대화 (고객이 상담 화면에서 고른 답입니다. 사실로 단정하지 말고 말투와 10번 항목에 자연스럽게 반영해 주세요): {키}: {값} / {키}: {값} / … / 지금 상황: {고른 상황}
```

**궁합사주**는 고객 정보 다음 줄에 상대 정보를 같은 형식으로 한 줄 더 넣어요.
```
상대 정보: 이름 {상대 이름}, {년}년 {월}월 {일}일 {양력|음력}, {태어난 시간 | 시간 모름 → 시주 제외}생, {성별}.
상대 만세력 기준 사주 구성: 년주 …, 월주 …, 일주 …, 시주 …. 이 여덟 글자를 확정된 것으로 보고 해석해 주세요.
```

**인생사주**는 대운 방향이 성별로 바뀌어서, 대운 목록도 계산해서 붙여요.
```
대운 (만세력 기준, {순행|역행}, {대운 시작 나이}세 시작): {나이}~{나이}세 {간지} / …
```

### 사이트에서 받는 값과 연결

| 덩어리 칸 | 사이트 값 | 비고 |
|---|---|---|
| 이름 | `state.name` | |
| 생년월일, 양력·음력, 윤달 | `state.birth`, `state.cal`, `state.leap` | |
| 태어난 시간 | `state.time` | 사이트는 시진(2시간 단위)으로 받아요. "진시(07~09시)"처럼 넣어요. 없으면 "시간 모름 → 시주 제외". |
| 성별 | `state.gender` | |
| 궁금한 점 | `state.want` | 마지막 화면에서 고른 질문 |
| 참고 대화 | `state.talk` + `state.status` | 장면마다 고른 답 (예: 계기: 마음에 둔 사람 / 바라는 것: 가까워지길) |
| 상대 정보 (궁합) | `state.pname`, `pbirth`, `pcal`, `ptime`, `pgender` | |
| 여덟 글자, 대운 | 만세력 계산 결과 | 지금 샘플 화면 계산은 근사값이에요. 실제 서비스는 절입 시각·지역 시간 보정까지 하는 만세력 값을 넣어야 해요. |

### 채운 예시 (민님 예시 손님, 연애사주)

여덟 글자는 만세력 계산기(서울, 지역 시간 보정 포함)로 계산했어요.

```
고객 정보: 이름 ○○, 1992년 3월 15일 양력, 오전 7시 30분생, 여성, 궁금한 점: 올해 이직해도 괜찮을지.
만세력 기준 사주 구성: 년주 임신(壬申), 월주 계묘(癸卯), 일주 경인(庚寅), 시주 기묘(己卯). 이 여덟 글자를 확정된 것으로 보고 해석해 주세요.
참고 대화 (고객이 상담 화면에서 고른 답입니다. 사실로 단정하지 말고 말투와 10번 항목에 자연스럽게 반영해 주세요): 계기: 그냥 궁금해서 / 바라는 시기: 늦어도 제대로 / 마음이 닫힌 이유: 바빠서 여유가 없음 / 마음가짐: 반신반의 / 지금 상황: 혼자인 지 꽤 됐어요
먼저 1번 항목부터 작성해 주세요.
```

인생사주라면 여기에 한 줄을 더 붙여요.
```
대운 (만세력 기준, 역행, 3세 시작): 3~13세 임인 / 13~23세 신축 / 23~33세 경자 / 33~43세 기해 / 43~53세 무술 / 53~63세 정유 / 63~73세 병신 / 73~83세 을미
```

## B. 자동 생성용 (결제 후 PDF 자동 제작)

채팅에서는 "다음"을 눌러 가며 받으면 되지만, 사이트가 결제 직후 PDF를 자동으로 만들려면 사람이 "다음"을 누를 수 없어요. 그래서 **항목마다 한 번씩, 11번 호출**해요.

**바꾸는 곳은 [분량] 덩어리 한 곳뿐이에요.**
```
[분량] 각 항목은 소제목을 달고 4~6문단으로 씁니다. 항목마다 예시 상황 2개와 표 1개, 마지막에 체크리스트 3줄을 넣습니다. 요청받은 번호의 항목 하나만 작성하고, 다른 항목은 쓰지 않습니다. 인사말이나 "다음 항목에서는" 같은 연결 문장은 넣지 않습니다.
```

**호출 순서**
1. 시스템 프롬프트: 역할 + 원칙 + 목차 + 바꾼 분량 + 금지 + 면책 (상품마다 고정)
2. 1~11번을 차례로 호출해요. 매번 보내는 사용자 메시지는 이래요.
```
{손님 정보 덩어리}
앞에서 확정한 내용: {2번·3번 항목에서 나온 여덟 글자 표와 오행 요약, 3~5줄}
이번에는 {N}번 항목 '{제목}'을 작성해 주세요.
```
3. 11번 호출 때만 끝에 "마지막 항목이므로 면책 문장을 그대로 넣어 주세요."를 한 줄 더 붙여요.
4. 11개 결과를 순서대로 PDF 템플릿(표지 → 목차 → 항목마다 새 쪽 → 면책 쪽)에 넣어요.

**왜 "앞에서 확정한 내용"을 붙이나요?** 호출이 따로따로라 AI가 앞 항목을 기억하지 못해요. 2·3번 결과를 짧게 요약해 매번 붙이면, 7번에서 갑자기 다른 오행을 말하는 식의 앞뒤 안 맞는 풀이를 막을 수 있어요.

**발송 전 자동 검사** (책의 체크리스트를 코드로)
- 본문에 손님 이름이 들어갔는지
- 10번 항목에 고른 질문이 언급됐는지
- 11번 끝에 면책 문장이 원문 그대로 있는지
- '100%', '무조건' 같은 금지 단어가 없는지 (있으면 그 항목만 다시 생성)
- 여덟 글자가 입력값과 같은지

## PDF 템플릿 (결과 PDF)

민님 규칙대로 네 부분으로 만들어요. 샘플: `saju-ebook/pdf-template/sample-신년운세.pdf`, 템플릿 원본: `saju-ebook/pdf-template/report-template.html`

1. **표지**: 상품명, 손님 이름, 만든 날짜, 상품 캐릭터 이미지 (연애 한결, 궁합 홍연, 인생 백운 선생, 신년 연지)
2. **목차**: 11개 항목 그대로
3. **본문**: 항목마다 새 쪽에서 시작, 큰 소제목, 글자 크게(12pt), 줄 간격 1.9, 여백 넉넉히. 모든 쪽 아래에 쪽번호
4. **면책 페이지**: 마지막 한 쪽에 따로, 아래 문장을 그대로

> 이 리포트는 사주명리학을 바탕으로 AI가 해석하고 구성한 참고용 콘텐츠입니다. 실제 미래를 예측하거나 결과를 보장하지 않습니다. 건강·재정·법률에 관한 중요한 결정은 반드시 해당 분야 전문가와 상의해 주세요. 힘든 시기라면 혼자 견디지 마시고 전문 상담을 받아 보시기를 권합니다. 리포트는 참고와 재미의 목적으로만 활용해 주세요.

면책 문장은 두 군데에 들어가요. 프롬프트의 [면책] 문장은 AI가 11번 항목 끝에 쓰는 짧은 문장이고, 위의 긴 문장은 PDF 마지막 쪽에 템플릿이 고정으로 넣어요. 이 긴 문장은 인스타 프로필, 카톡 상품 안내에도 똑같이 넣으면 돼요.

### 자동 제작 순서
1. 결제 완료 → 만세력으로 여덟 글자(인생사주는 대운까지) 계산
2. 위 B 방식으로 11번 호출해 항목 11개 받기
3. 발송 전 자동 검사 통과 확인
4. 템플릿에 표지 정보와 항목 11개 넣기 → PDF로 저장 (파일명: `○○님_신년운세_리포트.pdf`)
5. 메일 발송, 웹 결과 화면에도 같은 본문 표시
