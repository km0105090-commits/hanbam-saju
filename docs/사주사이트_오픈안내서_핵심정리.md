# 「사주 사이트 오픈 안내서」 핵심 정리

> 원본: 사주사이트오픈안내서1 1.pdf (3쪽, 2026년 10월 기준, 1달러=1,400원 환산)
> 정리일: 2026-11-18

## 0. 이 문서의 정체 (먼저 알아둘 것)

- **사이트 제작 외주업체가 계약한 고객("사장님")에게 주는 오픈 준비 안내서**다. 사주 공부 자료가 아니라 "자동판매 사이트를 맡기면 고객이 준비할 것 + 운영비" 문서.
- 문구 근거: "계약 즉시 사업자등록부터", "약관·방침 페이지는 제가 만들어 드리니", "납품 완료 시점", "납품 후 30일 무상 수정".
- **외주 제작비(계약 금액)는 문서에 없다.** 아래 비용은 전부 제작비를 뺀 운영비다. 이 업체에 맡길지 판단하려면 제작비를 따로 물어봐야 한다.
- 장점으로 볼 부분: 모든 계정을 **본인 명의로 개설**(소유권 100% 본인). 외주를 맡기더라도 이 조건은 꼭 지킬 것.

## 1. 사이트 구성 (기술 스택 7개)

| 서비스 | 역할 | 비용 | 소요 |
|---|---|---|---|
| 도메인 (가비아·후이즈) | 사이트 주소 | 연 2만 원 | 10분 |
| Vercel | 사이트 서버(24시간) | 월 $20 (상업용은 유료 필수) | 15분 |
| Supabase | 주문·고객·결과 DB | 무료 → 월 $25 (500MB/월 5GB 넘으면) | 15분 |
| Claude API | 사주 풀이 AI | 건당 100~600원, 선불 충전 | 20분 |
| 토스페이먼츠 | 카드 결제·정산 (PG) | 가입비 22만 + 연관리비 11만 | 3~7영업일, 심사 |
| Resend | 결과지 이메일 발송 | 무료 | 20분 |
| 카카오 디벨로퍼스 | 카카오 간편 로그인 | 무료 | 검수 1~3일 |

- 선택: 카카오 알림톡(솔라피, 건당 약 10원), 메타 광고 계정, 네이버 서치어드바이저.
- **필수 준비물: 해외결제 되는 신용카드** (Vercel·Supabase·Claude API는 달러 결제, 국내 전용 카드 불가).
- 흐름: 손님 로그인(카카오) → 정보 입력·결제(토스) → AI가 풀이 생성(Claude) → DB 저장(Supabase) → 이메일로 결과지 발송(Resend).

## 2. 서류와 사이트 표기 (법적 필수)

| 서류 | 발급처 | 소요 | 비용 |
|---|---|---|---|
| 사업자등록증 (업태 정보통신업 / 종목 전자상거래업) | 홈택스·세무서 | 1~3일 | 무료 |
| 통신판매업 신고증 | 정부24·구청 | 3~7일 | 연 4만 원 내외 (등록면허세, 매년 1월) |
| 정산 계좌 (사업자 명의 권장) | 은행 | 당일 | 무료 |
| 고객센터 이메일 | 네이버·구글 | 당일 | 무료 |
| 고객센터 전화 (070 번호, 아톡 앱) | 앱 | 당일 | 월 소액 |

- **순서 고정: 사업자등록 → 통신판매업 신고 → PG(토스) 심사.** 앞 단계가 끝나야 다음 진행 가능 → 가장 먼저 사업자등록.
- 사이트 하단 표기 6가지: 상호·대표자명·사업자등록번호·통신판매업 신고번호·사업장 주소·연락처.
- 이용약관·개인정보처리방침·환불규정 페이지 필요.
- 전화번호는 하단에 공개되므로 개인 번호 대신 070 번호 권장 (스팸 방지).

## 3. 오픈 진행 순서

1. **서류**: 사업자등록 → 통신판매업 신고, 해외결제 카드 준비
2. **사이트 구축 (1~3주)**: 계정 개설·디자인·상품 세팅, 서버 배포·도메인 연결
3. **결제 연동 (심사 후 1일)**: 결제·카카오·이메일 연동, 관리자 교육

- 심사를 기다리지 않고 **사이트 먼저 열고 결제를 나중에 붙이는 2단계** 방식.
- 심사 기간은 본인 명의라 앞당길 수 없고, 외주 작업 기간에 포함되지 않음.

- 결제수단별 수수료: 카드 3.2~3.5%, 간편결제 3%대, 계좌이체 약 1.8%, 휴대폰 약 3.8%. 최종 요율은 심사·계약 때 확정.
- AI 사용료 월 합계(건당 평균 250원 가정): 50건 1.25만 / 100건 2.5만 / 200건 5만 / 500건 12.5만 / 1,000건 25만 원.
- 문서의 손익분기 주장: 3,900원 상품 월 11건이면 고정비 충당, 월 200건(매출 80만)이면 약 68만 원 남음.

### 직접 검산한 결과
- 표의 합계·수수료 계산은 맞다 (3.9만/7.4만/29.4만 모두 일치).
- 손익분기: 3,521원 × 11건 = 38,731원으로 3.89만 원에 약간 못 미쳐 **실제로는 12건**. 사소한 차이.
- 월 200건 계산은 상품 구성을 평균 4,000원으로 잡은 값. 문서가 빠뜨린 비용(아래 5번)과 **세금·광고비·제작비**를 빼기 전 금액이다.

## 5. 검증 안 된 주장 / 빠진 것 (주의)

**검증 안 된 홍보성 주장**
- "정산 평균 5일 이내 (PG 업계 평균 15일)": 출처 없음. 토스 정산 주기는 계약 조건에 따라 다르므로 계약서에서 직접 확인.
- "보증보험 업계 통상 500만 원 → 면제": 신규·소규모 가맹점은 심사 결과에 따라 보증보험을 요구받을 수 있다. 확정 아님.
- "합쳐도 판매가의 3~6%", "손님이 늘수록 이익도 늘어난다": 광고비·환불·인건비를 뺀 원가 기준이라 실제 이익률과는 다르다.
- "AI 사용료는 넉넉히 잡은 상한값": 출력 분량·모델에 따라 달라진다. 전자책식 40~100쪽 리포트라면 건당 600원을 넘을 수 있다.
- "결제 연동 심사 후 1일": 외주업체의 작업 약속이지 보장이 아니다.

**문서에 없는 것**
- **외주 제작비**, 유지보수 비용(31일째부터), 기능 추가 단가.
- 부가세·종합소득세 (매출 80만 원이 순수익이 아님).
- 광고비 (메타 광고 계정은 언급만 하고 비용 없음).
- 소스코드·관리자 권한 인도 여부 (계정은 본인 명의라도 코드 소유권은 계약서로 확인 필요).
- 생년월일시 = 개인정보이므로 처리방침·보관기간·삭제 정책 구체 내용.
- 간이과세자는 통신판매업 신고 면제 대상일 수 있으나, PG 심사 때 신고증을 요구하는 경우가 많다.

## 6. 기존 자료와 비교

### 겹치는 것
- **2단계 자동판매 사이트 방향**: 전자책 부록 B의 "입력 폼 → 결제 → AI 생성 → 자동 발송"과 같은 구조. 이 안내서는 그걸 실제 서비스 이름과 금액으로 구체화한 버전.
- **사업자등록·PG 가입 장벽**: 전자책의 "자주 막히는 곳(결제 대행 가입에 사업자·사이트 주소 필요)", "개인정보 처리방침 부재"와 동일.
- **도메인 메일 발송**: 전자책의 "스팸함 문제(도메인 메일)" 해결책이 Resend + 자체 도메인.
- **상품 쪼개기**: 김해준 영상의 상품 세분화(연애·재회·궁합·직업)와 같은 방향.

### 새로운 것
- 구체적 기술 스택 7개와 계정별 소요 시간.
- 서류 발급 순서와 사이트 하단 법정 표기 6항목, 070 번호 팁.
- 초기비·월 고정비·건당 원가까지 숫자로 계산된 운영비 구조.
- 해외결제 카드 필요성.
- **가격대가 크게 다르다**: 전자책은 PDF 1건 2~4만 원대(1만 원 이하는 "대충 뽑나" 의심), 이 안내서는 990원~2.49만 원의 저가·다품목. 전자책=수동·고가·소량, 안내서=자동·저가·다량 모델. 김해준 퍼널(무료 사주 → 유료 결제)의 미끼·입문 상품으로는 990~4,900원대가 맞는다.

### 판단 메모
- 1단계(카톡+계좌이체)는 이 비용이 전혀 필요 없다. 사이트는 주문이 꾸준히 생긴 뒤에 가는 게 안전하다.
- 사이트로 갈 때 고정비는 월 4만 원 수준이라 부담이 작고, 큰 돈은 **토스 가입비 22만 원 + 외주 제작비**다.
- 성수기(12~1월) 전에 열려면 서류(1~2주)+구축(1~3주)+PG 심사(1주)로 최소 3~6주 필요. 지금(11월 중순) 시작해도 12월 말이 빠듯하다.
